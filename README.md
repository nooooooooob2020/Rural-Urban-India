# Rural-Urban Classification of Indian Settlements

A data-driven framework for re-examining the rural-urban divide in India using settlement-level socioeconomic, infrastructure and remotely sensed indicators.

## Objective

To develop a continuous Rural-Urban Index that captures the gradual transition between rural and urban settlements beyond conventional administrative classifications.

## Methodology

- SHRUG dataset used to construct a nationwide settlement-level analytical dataset
- Data preprocessing, transformation and missing-value handling
- Correlation pruning and ANOVA F-value based feature selection
- Two-stage hierarchical Principal Component Analysis (PCA)
- K-means clustering (k = 5) for continuous settlement classification
- GIS-based spatial analysis of settlement categories across India

## Classification

Settlements were classified into five levels:

- Deep Rural
- Rural
- Transitional
- Emerging Urban
- Highly Urbanized

## Results

The framework identifies intermediate and transitional settlements that are not adequately represented by the conventional rural-urban binary classification.
